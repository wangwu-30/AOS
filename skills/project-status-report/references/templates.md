# 项目状态汇报模板（Project Status Report Templates）

## 目录

- 通用模板
- 管理层简版
- 风险导向版
- 信息缺失时的最小模板

## 通用模板

```md
当前状态
- [事实 1]
- [事实 2]
- 当前判断：[按计划 / 有偏差 / 存在阻塞]

目标状态
- [目标结果]
- 验收线：[里程碑 / 日期 / 指标]

差距
- 还缺 [事项]
- 主要阻碍是 [风险 / 依赖 / 资源 / 决策]
- 若不处理，可能导致 [影响]

下一步计划
- [动作 1]，负责人 [人/角色]，时间点 [日期]
- [动作 2]，负责人 [人/角色]，时间点 [日期]
```

## 管理层简版

适用于需要快速传达是否健康、是否需要支持的场景。

```md
当前状态
- 项目目前 [按计划 / 轻微偏差 / 明显偏差]。
- 已完成 [关键结果]，当前最大问题是 [问题]。

目标状态
- 在 [日期] 前达到 [目标/里程碑]。

差距
- 当前距离目标还差 [关键缺口]。
- 需要的支持是 [决策 / 资源 / 外部协同]。

下一步计划
- [动作]，预计在 [日期] 前完成。
- 若 [条件] 未满足，将升级处理 [风险]。
```

## 风险导向版

适用于延期、故障恢复、验收前冲刺等场景。

```md
当前状态
- 已发生/已识别风险：[风险]
- 当前影响范围：[范围]
- 已采取措施：[措施]

目标状态
- 恢复到 [目标状态]
- 在 [日期] 前恢复 [服务/交付/里程碑]

差距
- 尚未解决：[问题]
- 根因或关键约束：[约束]
- 剩余风险：[风险]

下一步计划
- [修复动作]
- [验证动作]
- [沟通动作]
```

## 信息缺失时的最小模板

适用于上下文不完整但必须先产出状态汇报草稿的场景。

```md
当前状态
- 已确认事实：[事实]
- 待确认项：[未知]

目标状态
- 基于当前信息，目标应为 [推定目标]。

差距
- 目前无法确认 [差距项]，需要补充 [信息]。

下一步计划
- 先确认 [信息]
- 再推进 [动作]
```
