## Decision 001: 引入本地 Skill Registry（local-only）与 registry:// 内容寻址 skill_ref

- **状态**: `accepted`
- **结论**:
  - `registry_id` 以 ASVP `manifest.json` 的 canonical bytes 为唯一哈希输入，生成稳定内容寻址 ID；
  - 本地索引 `data/registry/index.json` 维护 `registry_id -> skill_dir` 只读映射；
  - LocalExecutor 在执行前解析 `registry://...` 并产出 resolution evidence（routing），解析失败 fail-closed；
  - ASVP verify 语义不变（registry 仅解析到目录路径，后续仍走现有 verify）。

## Gate（必须通过的门禁）

- 不破坏现有契约（Non-breaking）：
  - 既有 CLI 子命令的稳定 JSON 输出字段集合不变（只允许新增子命令/新增字段）。
  - ASVP verify 语义不变：registry 解析到 `skill_dir` 后仍必须走现有 verify 路径。
- Fail-Closed 不降级：
  - `registry://...` 解析失败或缺少映射时必须拒绝执行，且写入 error evidence（不回退为 path）。
  - 解析到的 `skill_dir` 若 verify 失败，必须拒绝执行（等效 verify 失败）。
- Deterministic（可复现）：
  - 同一 `manifest.json` canonical bytes 必须生成同一 `registry_id`（锁测试）。
